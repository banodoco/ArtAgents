# m8 — Packaged GA gate (sprint-plan Sprint 8)

Normative references: `docs/unified-data-model-plan-v10-20260813.md` (§2 layering, §5.3 items 11–12, §8), `docs/astrid-first-sprint-plan-20260813.md` (Sprint 8), `docs/astrid-first-sprint-plan-review-20260813.md` (fix 7 — final item 11 proof lives here). Plugin/generalization feedback source: `docs/openrouter-chat-20260814-plugin-data.md`.

## Outcome

The release artifact itself proves GA: a clean, installable package (per the frozen OS/browser/package matrix) installs on a clean account, runs `serve`, opens the editor, and supports project/timeline/media/references/backup/doctor with zero account/cloud/provider configuration; the installed artifact's help exposes exactly eight top-level families with the declared kernel/pack ownership and nested mounts; static + runtime scans find no Supabase domain writer, no semantic JSON/JSONL/FSA writer, no plan/session/thread/lease authority, no silent fallback, no kernel-to-pack FK, and no pack-owned writer. The factoring test proves an in-tree pack can be removed from a test configuration while the entire kernel suite remains green, and a second-agent schema sketch adds its own packs without changing a kernel table. Every GA item 1–12 is evidenced against the INSTALLED artifact; `astrid-first` is declared shipped.

## Scope

IN:
- Packaging: build/install/signing (per matrix), first-run experience, version checks (too-new schema refusal), bundle hygiene (no dev-only imports, no legacy modules, import-lint green on the artifact).
- Installed-artifact verification: GA items 1–12 run against the packaged product on the declared matrix (at minimum macOS, per decision artifact); help/verb census; static + runtime authority scans; core/installed-pack catalog and migration-state validation.
- Pack factorability: run the kernel suite with each domain pack omitted from a test configuration (and its declared tables absent), prove the kernel stays green, and check a concrete second-agent pack/schema sketch against the unchanged 14 kernel tables. Run FK-direction, namespaced-registry, and no-direct-writer lint against the installed sources/artifact.
- Release evidence pack: conformance + crash + contention + backup/restore reports, performance report, clean-account journey recording, authority census.
- Ship declaration + handoff notes (what the editor/hosting later stages will wrap).

OUT: anything beyond Astrid-first (editor rewrite, hosting, remote GPU, experiments, publish — each a separate future milestone).

## Locked decisions

- The v10 completion definition is the gate: "the release artifact contains one semantic authority with none of v9's legacy preservation machinery."
- Platform matrix from the decision artifact is the tested surface; anything else is documented as unsupported, not silently tested.

## Open questions

## Constraints

- No feature work; no schema changes; no dynamic plugin loader; fixes to packaging/verification only; a GA failure means fix + re-run, not scope cut; buffer may not add deferred features.

## Done Criteria

Installed artifact passes GA items 1–12 on the declared matrix; eight-family help census exact; authority and plugin-boundary scans clean; removing any domain pack from the test configuration leaves the full kernel suite green; the second-agent sketch requires no kernel-table change; clean-account journey recorded; evidence pack complete; ship declared.
