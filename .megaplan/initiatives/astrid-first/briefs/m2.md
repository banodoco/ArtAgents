# m2 — Executor and media foundations (sprint-plan Sprint 2)

Normative references: `docs/unified-data-model-plan-v10-20260813.md` (§2 schema/layering, §5.1 invariants), `docs/astrid-first-sprint-plan-20260813.md` (Sprint 2), `docs/astrid-first-sprint-plan-review-20260813.md` (fixes 2/3/5). Plugin/generalization feedback source: `docs/openrouter-chat-20260814-plugin-data.md`.

## Outcome

Two agent-agnostic kernel foundations that everything else executes on: (1) the **task executor** — admission (immutable executable spec, claim or fenced attempt), `task_dependencies` ordering, attempt fencing via `status_version`, heartbeat as runtime state only, versioned cancel/retry, and materialization into `task_outputs` via receipt-protected exactly-once commits, with the five named task races proven by tests; (2) the **media pipeline** — import (walk/hash/probe/dedupe), managed-copy storage under the m1-decided layout, staging + atomic publish, `media`/`media_locations`/`media_relations` rows in the same transaction as events/receipt, missing/mutation detection. Media is explicitly kernel citizenship—`task_outputs.media_id` is portable coupling for creative assets, source files, diffs, logs, and test reports—not a pack. Consumes the m1 decision artifact (media root/layout, relation kinds) as a frozen input.

## Scope

IN:
- Executor: local handler adapter (one real generator or renderer per v10 §5.3 item 2 — pick one capability from the parts bin), attempt lifecycle, race matrix (stale-complete, cancel-vs-complete, retry, orphan recovery, dual-materialize), run creation for fan-out (runs table; child tasks with `run_id`/`run_ordinal` — NO step table), group progress derived, group cancel/retry over eligible children.
- Media: import command internals (repository-owned), hash/probe pipeline, dedupe within project, staging + atomic publish + startup GC of unreferenced staging, locations (managed + external-reference), relations (kinds from artifact), verification/missing detection, byte SHA-256 as sole identity (path hashes never identity).
- Tests: media event-order/head/receipt/replay/mismatch/statement-boundary suite (review fix 5); executor race tests; contention under heartbeat + import.

OUT: references/shots implementations (m3), bridge beyond thin routes (m4), CLI/SDK (m4–m5), backup/doctor (m6), packaging (m6).

## Locked decisions

- v10 invariants: event universality (media mutations are events with receipts), atomic commits, attempt fencing, terminal immutability, single writer, byte-hash identity.
- Decision artifact values (m1): media root/staging layout, relation kinds, fan-out max/continuation envelope — consumed frozen; any change reopens the m1 gate.
- No plan/steps; fan-out = run + direct child tasks + `task_dependencies`; one attempt one realm (local execution only — no remote adapter this milestone).
- Capability outputs quarantined in staging; repository materializes terminal result (review risk row).
- Media and executor repositories remain in `core/`; neither depends on timeline, shots, or references pack tables. Domain packs consume their IDs through the kernel UoW and registries established in m1.

## Open questions

- Which one real capability (generator/renderer) to adapt first (recommend: the simplest existing image-generation handler from `astrid/core/generation/backends/`); confirm it exposes an output manifest.
- Continuation-envelope behavior for fan-outs over the m1 maximum (chunked receipt-linked series).
- Batch partial-retry policy: all failed children vs selected subset (defer to m5 UI/CLI semantics; executor must support both shapes).

## Constraints

- GA items 2 and 4–5 from v10 §5.3: a real generation/render traverses task→attempt→event→media→outputs→receipt atomically; fan-out = one run + direct child tasks; crash injection proves old-or-complete; races proven.
- No remote execution; no GPU-required behavior; provider calls only via user-provided keys, never required for core journeys.
- Media bytes never enter SQLite; no URL/path as identity.

## Done Criteria

Sprint-2 gate: one real generation/render journey round-trips atomically; the five races and crash injection green; media import dedupes, detects mutation/missing, and rejects path-identity; relation kinds from the artifact enforced; group progress/cancel/retry works without a step table; editor save lane still green (no regression from m1).
