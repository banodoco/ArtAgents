## Ranked findings

1. **Port bind race** — `_pick_free_port` (run.py:44-47) binds `127.0.0.1:0`, reads the port, closes the socket; `ThreadingHTTPServer` rebinds later (run.py:1453). Classic TOCTOU: another process can steal the port → OSError caught as "Permission denied (1100)" (1454-1455).
2. **Registry regeneration race** — `_regenerate_element_registries` (967-994) shells out to `scripts/gen_effect_registry.py` (check=True, cwd=REPO_ROOT, sanitized env). The generator writes shared outputs non-atomically via `write_text` (gen:355-361), touches theme symlink by unlink+recreate (gen:299-317), and has **no locking**. Two concurrent renders with different themes clobber `effects.generated.ts`; state file read/write (953-964) is also non-atomic → last-writer-wins.
3. **Fixed props path collision** — props at `out_path.parent / ".remotion-props.json"` (1446), written 1481, unlinked 1530. Concurrent renders sharing an output dir overwrite each other's props mid-flight.
4. **Silent success** — only `returncode` is checked (1511); zero-exit with no output file is treated as success and provenance written (1517). No timeout, no `start_new_session` on `npx remotion render` (1493-1510) — a hung render keeps the server (daemon thread, never joined, 1456/1529-1533) alive until process exit.
5. **Server root breadth** — `_server_root_for` (178-194) uses `os.path.commonpath` over all local assets; cross-project assets widen root toward the workspace. Traversal is guarded by stdlib `translate_path` + `directory=server_root` (1452), but CORS `*` (63) exposes everything under root to any webpage during the render.
6. **Staging** — content-addressed `public/astrid-effects/<render_hash>` (1459, hash at 997-1007, includes out path); identical concurrent renders share the dir and one's `rmtree` (1531) can break the other.

## Verified facts
Server root = common parent, enforced via `directory=`; Range: manual 206/416 handling + chunked copy (68-130); env sanitized (`build_child_subprocess_env`, subprocess_env.py:69-89,97-116 — secrets stripped, whitelist propagated, asserted at test_render_remotion_registry.py:770-832); registry cache = per-project hash state.
