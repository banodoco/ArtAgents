# ALPHA / TRANSPARENCY — verified findings

## 1. Hyperframes ✅ (flag + adapter change)
- Exact CLI: `npx hyperframes@0.7.107 render <ws> -c index.html -o out.mp4 --fps N --no-best-effort --strict` — **no `--format`, so mp4/h264 opaque** (render.py:525-540).
- Docs: `--format webm` → "produces VP9 with an alpha channel"; `--format mov` → ProRes 4444; `--format png-sequence` → RGBA frames (hyperframes.heygen.com/packages/cli). Transparent: `npx hyperframes render --format webm --output overlay.webm`.
- **Adapter blocks alpha**: `body{background:#000}` (render.py:286) + full-bleed bg div (render.py:304-312). Must skip both. Engine is headless Chrome + ffmpeg (npm: Node≥22, FFmpeg; `hyperframes browser/doctor`).

## 2. Remotion ✅ (flag only)
- Config blocks alpha: `Config.setVideoImageFormat('jpeg')` (remotion.config.ts:11); CLI call has no codec/pixel-format flags (remotion/run.py:556-568).
- Docs (remotion.dev/docs/transparent-videos): WebM: `--image-format=png --pixel-format=yuva420p --codec=vp8|vp9`; MOV: `--codec=prores --prores-profile=4444 --pixel-format=yuva444p10le`. Config API: `Config.setPixelFormat("yuva420p")`, `Config.setCodec("vp8")`. CLI flags override config. ANGLE irrelevant (encode is ffmpeg; angle only for GL — already set, remotion.config.ts:13).

## 3. three.js ✅ (component change)
- Only opaque element is `<color attach="background">` (ThreeTimelineComposition.tsx:409). R3F Canvas defaults to translucent renderer: `gl` defaults `{alpha:true, antialias:true}` + `setClearAlpha(0)` (r3f.docs.pmnd.rs/api/canvas); ThreeCanvas passes `...rest` through to R3F `<Canvas>` (remotion three/ThreeCanvas.tsx). Remove bg → alpha survives Remotion's PNG screenshot → yuva420p encode. `preserveDrawingBuffer` unnecessary for CDP capture.

## 4. ffmpeg
- WebM alpha: `-c:v libvpx-vp9 -pix_fmt yuva420p`. Native VP9 decoder drops alpha — force `-c:v libvpx-vp9` on input (ffmpeg trac #8468; hyperframes' own overlay example does exactly this). PNG = straight RGBA; ProRes = yuva444p10le.
- `overlay` expects **straight alpha** by default; `alpha=premultiplied` for premultiplied; `format=auto` picks output fmt from main input (ffmpeg.org/ffmpeg-filters.html).

## 5. Compositor consumer
Needs WebM/VP9+yuva420p (or PNG seq / ProRes 4444), libvpx decode, `overlay` after `scale` for resolution mismatch, `fps`/`setpts` alignment for fps mismatch. Note: current `rendering.ffmpeg-finalizer` is **temporal concat only, no spatial compositing** (docs/reference/threejs-renderer.md:144); compositor is net-new.
