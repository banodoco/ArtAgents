# E3 — Wan2GP headless driving contract

## Ranked findings
1. **Entry points are two-level.** Worker calls `HeadlessTaskQueue.submit_task` → `process_task_impl` (`task_processor.py`) → `WanOrchestrator.generate` (entrypoint shim `source.runtime.entrypoints.headless_wgp:WanOrchestrator`, doc 03 §1.2). Inside: `queue._switch_model(task.model)` → `orchestrator.load_model(model_key)`, then `wgp.generate_video` / `wgp.load_models` (wgp-report §3). Path choice is capability-driven: `generate_vace` (requires `video_guide`), `generate_flux`, else `generate_t2v` — `task_processor.py:500-570`.
2. **cwd/sys.path boundary.** Boot: `bootstrap_runtime_environment()` adds Wan2GP to path (`server.py:105-140`), then `os.chdir(wan2gp_path)`, `sys.argv=["worker.py"]`, `import wgp`, apply `--wgp-*` overrides to `wgp.server_config`; failure ⇒ preflight failed + exit(1) (`server.py:530-590`). Env spoofs: `WORKER_ID`, `WAN2GP_WORKER_MODE=true`. Astrid-side equivalent named in docs: `runtime_paths.ensure_wan2gp_on_path` + `wgp_bridge.py` + `wgp_patches.py`. Global patching (`phase_config`, SVI patches) happens under a lock with `finally` restore (`task_processor.py:_execute_generation_with_patches`).
3. **Config schema [GAP]** — no repo artifact lists `wgp_config.json` keys; boot "rewrites" it (wgp-report §3, doc 26). Exact key set must be read from the pinned submodule SHA `181bb71a21008032e4771e11663f33e4489c4512` (banodoco/Wan2GP, branch `reigh-sprint-3`, `.gitmodules`). Submodule source is **absent on this machine** (find confirms no `wgp.py`/`wgp_config.json` anywhere under /workspace).
4. **Preset mapping** (`TASK_TYPE_TO_MODEL`, doc 03 §3.4): `wan_2_2_t2i`→`t2v_2_2` (t2i forces `video_length=1`); `wan_2_2_i2v`→`i2v_14B`/`i2v_2_2`; vace family→`vace_14B_cocktail_2_2`; travel_segment/inpaint_frames/join_clips_segment→`wan_2_2_vace_lightning_baseline_2_2_2`; ltxv/ltx2→`ltxv_13B`/`ltx2_19B`; catalog-only `t2v`/`i2v` legacy keys map too. Profile-1 warm preload = `wan_2_2_i2v_lightning_baseline_2_2_2`, suppressed when tasks queued (`warm_cache.py`). Params whitelist incl. optional `model` override (`task_conversion.py:param_whitelist`).
5. **Checkpoint layout/download.** Presets: `Wan2GP/defaults/<key>.json` (+`finetunes/`); weights: `Wan2GP/ckpts/`, auto-download on first use (wgp-report §3). Preflight checks `models/` + `plugins/` dirs + writable `main_output_dir` (`preflight.py`). LoRAs arrive as task-param URLs downloaded during `convert_to_wgp_task`. Outputs land under WGP scratch then moved to `<main_output_dir>/<task_type>/<task_id>_<file>` (`output_paths.py`).
6. **Generation guardrails**: SIGALRM 1200s timeout (POSIX only), single-frame video→PNG conversion (3 cv2 retries), output existence re-check w/ 2s retry.
7. **CUDA-blocked [cannot verify here]**: actual `load_models`/`generate_video` execution, VRAM-profile/`server_config` override effects, ckpts auto-download integrity, warm-cache preload, real-generation SIGALRM behavior, gate-5 semantic baselines.
8. **Unverifiable anywhere until submodule vendored**: `wgp_config.json` key schema, `defaults/<key>.json` format — reconstruct only against pinned SHA.

## Five gates (doc 27 §9, line 349)
1. **Hermetic rebase/patch application** — fork rebased on upstream; `wgp_patches.py` applies clean at pinned SHA; submodule bump reproducible in sealed env. Reject: any patch conflict/drift (drift CI is report-only today).
2. **Path/import/config contract tests** — `ensure_wan2gp_on_path`, cwd=Wan2GP/, sys.argv spoof, `import wgp` succeeds, boot rewrites only `wgp_config.json`, `server_config` overrides applied.
3. **Dependency resolution per platform** — locked dep resolution (uv sync `--extra cuda124` upstream; Astrid equivalents) incl. `decord`/`smplfitter` stub story on every supported platform (Darwin-arm64 decord wheel gap known hazard).
4. **Conversion fixtures unchanged** — `db_task_to_generation_task`/`TaskConfig.from_db_task` fixtures byte-identical: param whitelist, prompt expansion, `video_length=1` forcing, LoRA URL download, defaults.
5. **Fixed-seed representative corpus** — seeded generations over representative capabilities; assert output shape (dims/fps/frame count) within deterministic tolerance + semantic diff vs prior build. Human review required outside demonstrated tolerances. Gates 1–4 reject mechanically; rollout drains WGP work, swaps sole binding/build-manifest `{wan2gp_sha, upstream_base, patchset_hash, worker_contract_version, preset/model/checkpoint hashes}`, retains prior build for rollback drill N+1 accepted ⇒ roll back to N proven.
