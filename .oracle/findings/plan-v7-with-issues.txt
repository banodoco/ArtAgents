# Megado plan v7 FINAL — minimal declarative storyboard layer

v7 incorporates accepted settled-wave cuts: single validator (no JSON Schema artifact), gen variants require alt_render_path (no paid branch), live text/image-synthesis compilation removed, timing overrides removed (meta default + --vo-align only), D2 collapsed, tracked canonical storyboard file.

## Canonical model

Storyboard = { version:1, meta:{title, canvas:"1920x1080@30", style:"pixel-terminal", timing:{default_hold}}, sections:[ Section ] }
Section = { id, nav:{tabs[2],active:0|1}, image:{variants:[Variant], active_index:int, resolved?:[{path,media_id,content_hash}]}, vo:{text, audio:{asset}} , provenance?:{prompt,generator?}, extras?:object(inert, preserved verbatim — holds former title/bullets/mink documentation) }

Variant = {source:"asset",path} | {source:"gen", prompt, alt_render_path(required in v1)}
Resolution: asset → import_file(path) ; gen → import_file(alt_render_path) ; both produce CAS record {path, media_id, content_hash}; section.image.resolved[i] mirrors variants (written back into the SAVED storyboard via compiler's return; the orchestrator persists it — storyboard file remains the source of truth).
Registry entry emitted per resolved asset: {"file": <CAS>, "content_sha256": digest, "origin": <section.provenance JSON>} ; generationId absent by policy.
Compiled timeline (per section): broll(resolved active image) + caption(verbatim vo.text) + vo audio(from wav probe duration) ; plus one brand wordmark. Intro fixture ⇒ exactly 76 clips / 50 assets / ~177.53s.

Unsupported-in-v1 (typed StoryboardError): other block kinds; gen without alt_render_path; duplicate ids; active_index out of range.
