## Verified facts
Silence synthesis is unconditional; track muted/volume never reach ffmpeg; visual adjustments silently dropped; fps=30 hardcoded in concat.

## Unknowns
Remotion-side handling of muted/volume/fades (props side); whether silent visual-adjustment dropping is relied upon.

## Risks
Extracting a backend finalizer with audio-ownership modes must: preserve always-audio contract, honor track muted/volume, reject or implement visual adjustments, parameterize fps/44100/192k, add binary pre-check.

## Suggested approach
Extract `_render_ffmpeg_media`/`_concat_segments` into a backend module with an `AudioOwnership` enum (synthesize|passthrough|none); close validation gaps first; add unit tests asserting constructed commands before refactor.
