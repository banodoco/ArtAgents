# rendering.threejs: wrap-vs-extract verdict

**1. Precedent seam exists — option (b) is already the codebase pattern.** `backends/ffmpeg/run.py:59` does `from ...backends.remotion import run as remotion_backend` and calls underscore-private helpers: `_render_provenance_payload` (ffmpeg/run.py:149,379,579), `_effective_registry_state` (:158,388,588), `_render_provenance_sidecar_path`, `_effect_registry_for_assets` (:300), `_source_pack_id` (:359). Import is side-effect-free: the sys.path hack only fires when `__package__ in {None,""}` (remotion/run.py:29–32); `scripts.gen_effect_registry` is defs-only (gen_effect_registry.py:16–57). No circularity.

**2. Launcher blocker + zero-edit bypass.** Pack-root launcher routes unknown ids to remotion via `else` (packs/rendering/run.py:104–115). But renderer.yaml `command:` is argv passed verbatim (transport.py:166–173; contracts.py:1938–1941), executed cwd=pack_root (service.py:1910). So `command: [python3, backends/threejs/run.py]` bypasses the launcher entirely. Only required edits: register in pack.yaml:44–46 (discovery, pack/registry.py:260–303) + new files. Zero `astrid/core` edits.

**3. Identity.** `RendererResolution` requires `support_decision.backend == renderer id` (contracts.py:1120–1121) → threejs `support()` emits `backend="rendering.threejs"` (cf. run.py:1046). Provenance v1 `engine` is a *parameter* (run.py:486,501) but call sites hardcode `"remotion"` (:764,1133) → pass `engine="threejs"`. `backend_fragments` hardcodes `BACKEND_ID` + `"renderer":"remotion"` (:1154–1161) → build own. `_settings_from_request` reads only `BACKEND_ID` namespace (:835) and `for_backend` filters config (contracts.py:885–900) → threejs needs its own ~40-line copy. `_protocol_render`/`render`/`support` are NOT reusable; `_execute_remotion` (:600, composition_id param), `_render_provenance_payload`, `_serialize_timeline` (:126), `_resolved_theme_for_render` (:172), `_stage_effect_assets_for_timeline` (:389), `_canonical_profile` (:887), `_write_failure` (:1184) are.

**4. Composition hook.** `composition_id` from `backend_config` (:845–848, default `TimelineComposition` :72) → `npx remotion render <id>` (:697). Backend-config-driven; add `<Composition id="ThreeTimelineComposition">` in remotion/src/Root.tsx (currently only :50–65).

**5. Lock.** One global `remotion/.astrid-registry.lock` (lock.py:33,120–137), non-recursive; guards registry regen (run.py:278–282). Reusing `_execute_remotion` acquires it (:613). Unlocked concurrent threejs/remotion renders would tear `effects.generated.ts`/`_active_theme`.

**Recommendation: (b)** — ffmpeg precedent, identity-correct thin shells, no core edits. (a) duplicates ~250 lines; (c) edits remotion run.py — YAGNI.
