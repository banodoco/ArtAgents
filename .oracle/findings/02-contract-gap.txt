## Verified findings (ranked)

**1. The plan validator is the hard wall.** `RenderPlan.__post_init__` (contracts.py:1429–1445) walks segments as a single time dimension: `expected_start` chains `segment.window.end_frame` → next `start_frame`; mismatch raises `"overlaps or is out of order"`/`"leaves a gap"` (1438–1440), plus `"trailing gap"` (1444–1445). `reasons` must be keyed one-per-segment by index (1447–1451). This is the exact invariant that forbids two segments sharing a frame (i.e., stacking).

**2. Segments carry zero layer surface.** `RenderSegment` (1306–1357): fields `window`, `renderer`, `input_hashes` only; `from_dict` `allowed` set is exactly those three (1351–1352). Docstring: "one complete temporal window assigned to one qualified backend" (1307). `FrameWindow` (388–448) is time-only: `start_frame/end_frame/fps_rational/source_range/speed`; validation start≥0 (398), end>start (400–401). No z/blend/opacity anywhere in contracts.py.

**3. Finalizer is concat-only, order=time.** `build_concat_command` (ffmpeg/run.py:658–695): ffconcat demuxer + `-c copy`, no filtergraph. `finalize` sums durations: `total_frames = sum(segment.window.duration_frames…)` (1371–1373) — overlapping layers double-count. `_preflight_segments` zips artifacts↔segments strict (1098–1100) and checks each against its window (1139–1141). `_validate_concat_output` asserts frame count = planned total (1296). No alpha handling exists anywhere (grep: zero matches in backends/finalizers; manifests declare no alpha/transparent/overlay — ffmpeg/threejs/remotion renderer.yaml all `supports_windows: false`).

**4. Host-slicing drops layer context.** `_window_timeline` (service.py:1097–1135) keeps only tracks whose ids appear in the window's clips (`used_tracks`, 1117–1121) — a windowed renderer can't see other layers' tracks.

**5. Planners are 1-D by construction.** legacy_hybrid `plan` (run.py:666–820) and threejs_hybrid `_window_plan`/`_assert_exact_tiling` (231–348: "no gaps, overlaps…" 334) emit non-overlapping tilings; planner.yaml:17: "V1 forbids overlay compositing."

**6. Capability channel can't carry alpha.** `SupportReport.features: dict[str, bool | str]` (contracts.py:910, 928–929) — no structured values.

**7. Tests locking the invariant.** `test_plan_rejects_gaps_overlaps_and_out_of_order_segments` (test_contracts.py:1084–1100: overlap/out-of-order/gap/trailing-gap cases); `test_plan_accepts_adjacent_segments_and_exact_window_coverage` (1074); `_assert_exact_tiling` (test_threejs_hybrid.py:154–178) used by ~11 tests; schema roundtrip fixtures (test_schema_roundtrip.py:66).

## Contract-change surface
1. `RenderPlan.__post_init__` (contracts.py:1429–1445): relax to per-layer tiling (group by `layer`, verify each layer tiles; allow cross-layer overlap).
2. `RenderSegment` (1306): add `layer` spec (`layer_id`, `z_order`, `blend_mode`, `opacity`).
3. `FrameWindow` (388): optionally accept `layer_id`/`z_order`.
4. `RenderPlan` (1361): add layer registry; relax `reasons` keying (1447–1451).
5. Finalizer (ffmpeg/run.py:658–695, 712–800, 1371): add overlay filtergraph assembly; replace duration-sum (1371) with layer-aware total.
6. `_window_timeline` (service.py:1117–1121): stop pruning non-window tracks when layers matter.
7. `SupportReport.features` (910): allow structured feature values (or new capability field).
8. Tests: test_contracts.py:1084–1100, test_threejs_hybrid.py:154; schema fixtures.
