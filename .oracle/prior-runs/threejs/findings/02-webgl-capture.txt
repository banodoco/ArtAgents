## Verified findings (ranked by relevance)

**1. `--gl=angle` is the documented fix for three.js — and the only GL knob.** `ChromiumOptions` = `{gl?: 'swangle'|'angle'|'egl'|'swiftshader'|'vulkan'|'angle-egl'|null, headless?, …}` — **no raw-args passthrough** (remotion.dev/docs/renderer/types). Default `gl: null` (Chrome decides); v4.0.455 logs `openBrowser() Opening browser: gl = undefined` (remotion#4300). Remotion 5.0 flips default to `angle`. @remotion/three docs' "Note on server-side rendering" explicitly prescribes `Config.setChromiumOpenGlRenderer('angle')` / `chromiumOptions.gl='angle'`.

**2. Browser: bundled Chrome Headless Shell, cached in-project.** Downloads to `node_modules/.remotion/chrome-headless-shell/[platform]/chrome-headless-shell` (remotion.dev/docs/miscellaneous/chrome-headless-shell; macOS path confirmed by codex#28180). System `/Applications/Google Chrome.app` v151 exists here but is unused absent `setBrowserExecutable` (not in `remotion/remotion.config.ts` — no GL config, identical in `Astrid`). No `node_modules`/`.remotion` cache exists locally; `~/Library/Caches/ms-playwright/chromium_headless_shell-1223` is Playwright's, not Remotion's.

**3. `ThreeCanvas` syncs deterministically already.** `ThreeCanvas.tsx` (fetched): `frameloop={isRendering ? 'never' : …}`, `advance(performance.now())` per `useCurrentFrame()`, gated by `useDelayRender('Waiting for <ThreeCanvas/> to be created')` + per-frame `'Waiting for R3F to render frame N'`. Capture proceeds only after WebGL presents — so **the only failure mode is WebGL context creation**.

**4. Failure mode on macOS arm64.** Chrome 129+ removed auto SwiftShader fallback — WebGL context creation **fails** GPU-less unless `--enable-unsafe-swiftshader` (chromestatus 5166674414927872). Main-branch `open-browser.ts` maps `angle` → `['--use-gl=angle','--enable-unsafe-swiftshader']`; `swangle` → `['--use-gl=angle','--use-angle=swiftshader']`. Chromium 40277080#49: Mac ARM headless WebGL can land `DISPLAY_COMPOSITOR`→WebGL=Disabled via the Graphite ladder — verify v4.0.455's mapping with `grep -n "unsafe-swiftshader" node_modules/@remotion/renderer/dist/esm/*.js` after install.

**5. Execution: impossible here** — no terminal tool, no `node_modules`. Try: `npx remotion still src/index.ts ThreeBasic --gl=angle --frame=0 out.jpg` at 160×90.

**6. CI flags:** `backend_config={"rendering.remotion": {…}}` / `worker_remotion.py` cmd (lines 126–135) should append `--gl=angle`; prefer `Config.setChromiumOpenGlRenderer('angle')` in `remotion.config.ts` so all entry points inherit it.
