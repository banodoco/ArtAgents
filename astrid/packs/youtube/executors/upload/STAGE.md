# Upload to YouTube

**Executor**: `youtube.upload`  
**Status**: implemented  
**Kind**: service executor (external API)

Uploads a finished video to YouTube via the shared **banodoco-social Zapier
integration**. The executor posts video metadata (URL, title, description,
tags, privacy settings) to a Zapier webhook, which handles OAuth
authentication and the actual YouTube Data API call.

## Requirements

- **Reachable HTTP(S) URL** for the finished video — the video must be
  publicly accessible or served from a URL that Zapier/YouTube can fetch
- **banodoco-social Zapier** webhook must be configured and reachable

The executor does NOT handle video file upload directly — it sends a URL
that YouTube's ingestion pipeline fetches. This means the video must be
hosted somewhere accessible (e.g., a public S3 bucket, a CDN, or a local
server with a public tunnel).

## Quick-start

```python
import astrid.sdk as sdk
result = sdk.invoke(
    "youtube.upload",
        kind="executor", project="demo",
    inputs={
        "video_url": "https://example.com/hype.mp4",
        "title": "My Hype Video",
        "description": "Generated by Astrid",
        "tags": "hype,astrid,auto-generated",
    },
)
```

With privacy and playlist:

```python
import astrid.sdk as sdk
result = sdk.invoke(
    "youtube.upload",
        kind="executor", project="demo",
    inputs={
        "video_url": "https://example.com/hype.mp4",
        "title": "My Hype Video",
        "description": "Generated by Astrid",
        "privacy_status": "unlisted",
        "playlist_id": "PLabc123",
        "tag": ["hype", "astrid"],
    },
)
```

## Inputs

| Name           | Type    | Required | Description                                |
|----------------|---------|----------|--------------------------------------------|
| video_url      | string  | yes      | Reachable http(s) URL for the finished video |
| title          | string  | yes      | YouTube video title                        |
| description    | string  | yes      | YouTube video description                  |
| tag            | string  | no       | Individual YouTube tag (repeatable)        |
| tags           | string  | no       | Comma-separated YouTube tags               |
| privacy_status | string  | no       | `private`, `unlisted`, or `public`         |
| playlist_id    | string  | no       | Optional YouTube playlist ID               |
| made_for_kids  | boolean | no       | Mark the video as made for kids            |

## Pipeline position

Terminal service executor — runs optionally after `rendering.render`. Not
part of the numbered editorial pipeline.

## Depends on

None declared in the dependency graph.

## Integration

- **Backend**: `banodoco-social` (Zapier webhook)
- **Callable**: `publish_youtube_video` in `astrid.packs.youtube.executors.upload.src.social_publish`
