# ✦ &nbsp; A S T R I D &nbsp; ✦

**a harness for agents and humans to make art**

*A Python SDK for building and running open-source agentic UXes.*

</div>

---

<div align="center">

### Get started

</div>

```bash
git clone https://github.com/peteromallet/Astrid.git
cd Astrid
pip install -e .

python3 -m astrid --help
```

<div align="center">

`--help` is the map — every command lives there. Start there and explore.

<br>

An **executor** does one piece of work · an **orchestrator** combines them.

</div>

```bash
python3 -m astrid executors run <id> -- <args>
python3 -m astrid orchestrators run <id> -- <args>
```
