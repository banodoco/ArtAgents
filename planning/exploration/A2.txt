## Elegant simplifications

### One canonical formula set

The unified helper should live in a single location (proposed: `astrid/core/timeline/duration.py`) and export exactly:

```python
def clip_duration_seconds(clip: dict) -> float:
    """Canonical clip duration. hold takes precedence over from/to/speed."""
    hold = clip.get("hold")
    if isinstance(hold, (int, float)) and float(hold) >= 0:
        return float(hold)
    start = float(clip.get("from", 0) or 0)
    end = float(clip.get("to", start) or start)
    speed = float(clip.get("speed", 1) or 1)
    if speed <= 0:
        return 0.0
    return max(0.0, end - start) / speed

def clip_end_seconds(clip: dict) -> float:
    return float(clip.get("at", 0) or 0) + clip_duration_seconds(clip)

def timeline_duration_seconds(timeline: dict, *, track_kinds: set[str] | None = None) -> float:
    explicit = (timeline.get("metadata", {}) or {}).get("duration_seconds")
    if isinstance(explicit, (int, float)):
        return float(explicit)
    tracks = {t["id"]: t for t in timeline.get("tracks", []) if isinstance(t, dict)}
    clips = timeline.get("clips", [])
    if track_kinds is not None:
        track_ids = {tid for tid, t in tracks.items() if t.get("kind") in track_kinds}
        clips = [c for c in clips if c.get("track") in track_ids]
    return max((clip_end_seconds(c) for c in clips), default=0.0)
```

This replaces 3 divergent implementations and handles the audio-vs-visual split via `track_kinds={"visual"}` vs default (all).

### Time-scaled layout uses visual-only duration

For visualization, `time-scaled` mode should default to `track_kinds={"visual"}` for its horizontal span. The total duration (98s) appears as an annotation. This avoids the empty-space problem and matches what a human would consider "the timeline's visual extent."

### Desert fixture truth is simple

The fixture uses `hold` exclusively (no `from`/`to`/`speed` on any clip). The unified formula reduces to `at + hold` for all clips. The only complexity is the audio track extending the total — which the `track_kinds` parameter cleanly separates.
