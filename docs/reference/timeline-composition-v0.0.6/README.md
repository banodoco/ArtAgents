# timeline-composition v0.0.6 reference

This directory is a read-only parity reference copied from the installed
`@banodoco/timeline-composition` package's `typescript/src/` directory.  The
version is pinned to **v0.0.6** by `remotion/package.json`.

Source URL:
`https://github.com/banodoco/timeline-composition/archive/refs/tags/v0.0.6.tar.gz`

Astrid's canonical Python duration contract and parity fixtures cite this
snapshot so their behavior can be reviewed without installing Node packages.
The dependency under `remotion/node_modules` may be reinstalled, regenerated,
or updated without changing this frozen snapshot.  Update this directory only
as an explicit compositor-contract version change.

The installed `typescript/src/` directory contained 20 files when frozen.  The
earlier exploration note described 17; the snapshot deliberately preserves
all 20 files actually used by the installed compositor, including generated
registry modules.
